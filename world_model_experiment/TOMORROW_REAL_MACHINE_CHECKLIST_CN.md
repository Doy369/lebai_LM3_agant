原则：每一级通过后才能进入下一级；任何一级异常都回退，不跨级操作。

## 0. 通电前人工检查

- [ ] 相机支架、夹爪、标定板和桌面均已刚性固定
- [ ] 机械臂运动范围内无人、无松散线缆、无无关物品
- [ ] 实体急停位置明确且操作者能够立即触达
- [ ] 夹爪和相机线缆不会进入关节运动范围
- [ ] 实验物体不透明、不易碎、质量和尺寸适合夹爪
- [ ] 放置点与抓取点均在已验证工作空间内
- [ ] 关闭 OrbbecViewer、系统相机和其它占用相机的软件

## 1. 离线门禁

打开一个新的PowerShell，不设置任何真机运动变量，执行：

```powershell
.\world_model_experiment\tomorrow_tools.bat preflight
```

- [ ] `calibration` 为 pass
- [ ] `core_dependencies` 为 pass
- [ ] `orbbec_sdk` 为 pass
- [ ] `lebai_sdk` 为 pass
- [ ] `ready_for_real_motion` 必须保持 false（这是正确结果）
- [ ] 已保存预检JSON报告

## 2. 真实相机只读门禁

先设置Qwen API Key，再执行：

```powershell
$env:QWEN_API_KEY="你的密钥"
.\world_model_experiment\tomorrow_tools.bat camera "抓取红色杯子"
```

- [ ] 相机成功获取RGB和对齐深度
- [ ] 标注图中的目标框只覆盖目标本体
- [ ] 深度值处于现场合理范围
- [ ] Base坐标位于工作空间内
- [ ] 世界模型生成了多个候选
- [ ] 日志目录包含原图、标注图、原始规划、世界状态和决策
- [ ] 该步骤没有连接机械臂

至少更换3个目标和3种摆放位置，重复本步骤。

## 3. 机械臂只读门禁

确认机械臂与电脑同网段，执行：


- [ ] 连接成功
- [ ] 能读取六个关节角
- [ ] 能读取TCP位姿
- [ ] 没有调用 `start_sys`
- [ ] 没有移动机械臂
- [ ] 没有初始化或闭合夹爪
- [ ] 已保存机器人只读报告

- [ ] `LEBAI_DRY_RUN=1`
- [ ] 运行当前画面规划
- [ ] 检查抓取坐标、姿态和放置点

- [ ] 重复至少5次且结果稳定

## 5. 真机安全探测

只有前四级全部通过才能进入本级。

- [ ] 操作者手持急停并持续观察
- [ ] 机械臂速度使用现场最低安全值
- [ ] 首次只执行 `probe`，不闭合夹爪、不执行完整抓放
- [ ] 悬停点明显高于目标
- [ ] 下降余量保守
- [ ] 探测位置与目标实际位置一致
- [ ] 探测结束后机械臂安全退回
- [ ] probe lock内容与当前快照一致

至少完成3次不同位置的安全探测。

## 6. 首次完整抓取

- [ ] 只放置一个大尺寸、规则、非易碎目标
- [ ] 抓取点位于工作空间中央
- [ ] 周围没有其它物体
- [ ] 先probe，确认后复用probe lock执行pick
- [ ] 第一次只完成一次抓取，不连续循环
- [ ] 人工记录目标选择、是否抬起、是否滑落、是否正确放置
- [ ] 抓取失败后不自动无限重试

## 立即停止条件

出现任一情况立即停止并回退检查：

- 相机或标定支架发生位移；
- 目标框明显错误；
- 深度突然跳变或为零；
- Base坐标与物体实际方向相反；
- 机械臂状态异常或反复断连；
- TCP姿态与预期不一致；
- 轨迹靠近桌面、支架或相机；
- 夹爪线缆被拉扯；
- probe lock失效；
- 操作者无法持续控制急停。
